---

## 0. 왜 하나요? (1분 읽기)

선부동산 홈페이지가 **새 주소로 바뀌었어요.**

> **새 홈페이지 주소: `https://sanbon.lineestate.co.kr`**

손님이 「산본 부동산」, 「선부동산」을 검색하면 맨 위에 **지도·가게 카드**(전화, 위치, 홈페이지 버튼)가 먼저 떠요.
이 카드의 **홈페이지 칸에 새 주소가 들어가야** 손님이 매물 사이트로 바로 들어와요.

예전 주소(`linerealestate.vercel.app`)로 들어와도 새 주소로 자동으로 넘어가긴 해요. 그래도 새 주소로 바꿔 두는 게 정확하고 검색에도 좋아요.

## 3. ① 네이버 스마트플레이스 (가장 중요)

**필요한 것:** 선부동산 플레이스를 관리하는 **네이버 아이디**(대표 아이디이거나, 매니저로 초대받은 본인 아이디)

1. PC 또는 휴대폰에서 **https://new.smartplace.naver.com** 에 들어가 로그인해요.
2. **내 업체** 목록에서 **선부동산(선부동산공인중개사사무소)** 을 눌러요.
   - 목록에 없으면 → 내 아이디에 권한이 없는 거예요. **대표님 아이디로 로그인**하거나, 대표님께 **스마트플레이스 매니저 초대**를 부탁하세요. (대표 계정 → 업체 선택 → 설정/매니저 관리 → 초대)
3. 왼쪽(또는 아래) 메뉴에서 **업체정보** 를 눌러요.
4. **홈페이지** 항목을 찾아 **수정** → `https://sanbon.lineestate.co.kr` 입력 → **저장**.
   - 예전 주소(`linerealestate.vercel.app`)나 블로그 주소가 있으면 지우고 새 주소를 **첫 번째(대표)** 로 넣어요.
5. 같은 화면에서 **영업시간**도 2번 표의 시간과 맞는지 확인하고, 다르면 고쳐요.
6. 저장하면 네이버 검수 후 반영돼요(보통 하루 안).
7. **확인:** 다음 날 네이버에서 「선부동산 산본」 검색 → 가게 카드의 **홈페이지** 버튼을 눌러 새 사이트가 열리면 끝.

## 4. ② 카카오맵

**필요한 것:** 카카오 계정 (선부동산 장소를 관리하는 계정이면 가장 좋음)

### 방법 A — 장소 관리 권한이 있을 때
1. **https://business.kakao.com** 에 카카오 계정으로 로그인해요.
2. **장소 관리**(또는 '내 장소' / '카카오맵 장소') 메뉴로 가요.
3. **선부동산**을 고르고 **홈페이지** 칸에 `https://sanbon.lineestate.co.kr` → 저장.
4. 영업시간도 2번 표와 맞는지 확인해요.

### 방법 B — 장소 관리 메뉴에 선부동산이 없을 때 (가장 쉬움)
1. 휴대폰 **카카오맵 앱**에서 「선부동산」 검색 → 선부동산 장소를 눌러요.
2. 아래쪽 **정보 수정 제안**(또는 '장소 정보 수정 요청')을 눌러요.
3. **홈페이지** 항목에 `https://sanbon.lineestate.co.kr` 을 넣고 제출해요. (영업시간이 틀리면 같이 고쳐 제안)
4. 카카오 검토 후 반영돼요(며칠 걸릴 수 있음).
   - 나중에 정식으로 관리하려면 방법 A 화면에서 **"내 장소 등록(소유 확인)"** 을 진행하면 돼요. 사업자등록증이 필요할 수 있어요.

## 5. ③ 구글 비즈니스 프로필 (새로 만들기)

**지금 상태:** 구글에서 「선부동산 산본」을 검색하면 오른쪽에 **당근마켓 카드만** 뜨고, 구글 지도 가게 카드가 없어요. → **구글에는 아직 등록이 안 된 상태**예요. 그래서 "주소 바꾸기"가 아니라 **새로 만들기**예요.

(참고: 새 홈페이지는 이미 구글 검색 1등으로 나와요. 이건 지도 카드를 추가로 띄우는 작업이에요.)

**필요한 것:** 구글 계정 (선부동산용으로 계속 쓸 계정. 대표님 계정이나 사무실 계정 추천)

1. **https://business.google.com** 에 들어가 **지금 관리하기 / 시작하기** 를 눌러요.
2. **비즈니스 이름**: `선부동산공인중개사사무소` 입력.
   - 비슷한 이름이 목록에 뜨면 → 이미 누가 만들어 둔 거예요. 그걸 골라 **"소유권 요청"** 으로 진행해요.
3. **업종(카테고리)**: `부동산 중개업소` 를 골라요.
4. **손님이 방문할 수 있는 위치가 있나요?** → **예**, 주소: 2번 표의 주소 입력 (208호 포함).
5. **전화번호**: `031-344-8924` / **웹사이트**: `https://sanbon.lineestate.co.kr`
6. 마지막에 **본인 확인(소유 확인)** 방법을 골라요. 구글이 화면에 보여 주는 방법 중 하나예요:
   - **영상 녹화**: 휴대폰으로 사무실 간판·출입문·내부·사업자등록증 등을 한 번에 찍어 올리기 (가장 흔함)
   - **우편 엽서**: 사무실 주소로 엽서가 오면 거기 적힌 코드를 입력 (1~2주)
   - **전화/문자**: 화면에 나오면 가장 빠름
7. 확인이 끝나면(보통 며칠) 구글 지도와 검색에 가게 카드가 떠요.
8. 확인 후 **영업시간**(2번 표), **사진**(간판·사무실), **소개 한 줄**을 채워요.

> ⚠️ 구글은 가짜 정보·키워드 넣은 상호를 싫어해요. 상호는 **등록증 명칭 그대로**("선부동산공인중개사사무소") 쓰고, "산본 상가 임대" 같은 말을 상호에 붙이지 마세요.
