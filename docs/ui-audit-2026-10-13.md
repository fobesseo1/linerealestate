# 공개 화면 UI 점검 — 2026-10-13

## 발견·수정한 문제

1. 업종/월세 선택 필터: 기존 높이 30px에 상하 padding 20px가 들어가 텍스트 영역이 잘림.
   높이 44px, PC 글자 14px/모바일 16px, 적절한 padding으로 수정.
   표시명은 `전체 업종`/`월세 전체`; 초기화 버튼도 44px와 명확한 대비 적용.
2. 오른쪽 고정 도구: 이전 1180px 레이아웃의 `left` 값이 남아 1440px 콘텐츠 안쪽에 겹침.
   `left:auto`와 바깥 여백 기준 `right` 적용. 1920px 테스트에서 콘텐츠 끝과 도구 사이 28.5px 확보.
   1660px 이하에서 여백이 부족하면 고정 도구를 숨김; 상단 찜/상담 메뉴와 모바일 문의 바 유지.
3. 초기화/전체 검색 후 목록이 임대차와 매매를 함께 보여주는데 제목은 임대차로만 표시되던 부분:
   전체 결과일 때 `산본 상가 매물`, 임대차/매매 전용일 때 해당 제목 표시.
4. 요청된 홈 대표 카드 비율: 사진 표시 영역 PC 1.9:1, 모바일 1.65:1; 주소·제목·가격·전환 영역 여백 축소.
   1920px 테스트에서 사진 389.8px / 전체 카드 559.7px, 약 70%. 사진 원본 파일은 변경하지 않음.

## 확인한 범위

- 1920×1080, 390×844에서 홈, 목록, 중개 사례, 비용 비교, 상담 과정, 매물 상세, 완료 사례 상세 확인.
- 현재 공개 매물 6건과 완료 사례 4건 전체 상세의 모바일 가로 넘침 확인: 없음.
- PC 목록 고정 도구와 콘텐츠 겹침 없음. 좁은 화면에서 고정 도구 숨김 확인.
- 월세 150만원 이하 선택: 월세 120만원 매물로 필터링 확인. 조건 초기화 확인.
- 모바일 메뉴 확장 후 `내 점포 내놓기` 표시 확인.
- 목록/카드 제목·가격·선택 필터 글자, 상세 사진 목록, 공개 지도 영역, 문의 영역, 바닥 고정 문의 UI를 점검.
- 요청에 따른 스타일 점검이며 실제 고객 문의 전송, 데이터/계약 조건 변경은 하지 않음.

실시간 게시 자료가 바뀌면 건수와 카드 제목 길이도 달라질 수 있으므로 고정 높이로 긴 제목을 자르지 않는다.
