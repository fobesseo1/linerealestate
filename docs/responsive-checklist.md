## 점검 방법

- **폭:** 320(작은 폰), 360, 375(아이폰), 430(큰 폰), 768(태블릿 세로), 1024(태블릿 가로)
- **페이지 14곳:** 홈, 매물 목록(임대·매매), 매물 상세(사진 있음/없음), 중개 사례 목록·상세, 점포 비용 비교, 상담·계약 과정, 관리자 로그인, 테스트 페이지 4곳
- **상태:** 첫 화면 광고 영상, 모바일 메뉴 열림, 상담 요청 창(위/아래), 스크롤 위치별 캐릭터 말풍선
- **자동 측정 (Playwright):** 가로 넘침, 화면 밖으로 나간 요소, 고정 요소 위치, 28px 미만 터치 대상
- **화면 캡처:** 페이지 전체를 화면 높이 단위로 잘라 확인했습니다.
  - 수정 전: `.tmp/responsive-audit/`
  - 수정 후: `.tmp/responsive-audit/after/`
  - 두 폴더 모두 git에서 제외되어 있습니다.
- 화면 왼쪽 아래의 검은 "N" 동그라미는 Next.js 개발 모드 표시라 실제 사이트에는 나오지 않습니다.

우선순위: **P1** 내용이 가려지거나 잘림 · **P2** 어색하거나 쓰기 불편함 · **P3** 다듬기

### 다시 점검한 결과
- **가로 넘침:** 14개 페이지 × 6개 폭 = 84개 화면 모두 **0px**입니다(수정 전에는 320px에서 14곳).
- **28px 미만 터치 대상:** 우리 코드에는 없습니다. 남은 것은 네이버 지도 안의 저작권·'더보기' 링크뿐인데, 네이버가 그리는 부분이라 바꿀 수 없습니다.

## A. 공통 (모든 페이지)

- [x] **P1 검색창이 320px에서 화면 밖으로 나감**
  - 검색 폼이 줄어들 수 있게 해서(`min-w-0`) 320px에서도 화면 안에 들어옵니다. [site-header.tsx](components/site/site-header.tsx)
- [x] **P2 검색창 안내 문구가 잘림**
  - 문구를 "업종·키워드로 매물 검색"으로 줄였습니다. 320px부터 태블릿까지 잘리지 않습니다.
- [x] **P2 모바일 메뉴 줄이 잘려 있고 넘길 수 있다는 표시가 없음**
  - 메뉴 줄 오른쪽 끝에 어두운 그라데이션을 넣어 옆으로 더 있다는 것을 보여 줍니다. 마지막 항목도 끝까지 넘겨 볼 수 있게 오른쪽 여백을 줬습니다.
- [x] **P2 맨 위 빨간 띠 글자가 너무 작고 320에서 겹침**
  - 폰에서는 왼쪽 문구 하나만 11px로 보여 줍니다.
- [x] **P2 터치 대상이 작음**
  - 커진 것: '움직임 끄기'(높이 32px), 메뉴 버튼(44px), 빵부스러기 '홈', 바닥글 전화·관리자 링크, 홈 '매물 자세히', 입점 기록 '중개 사례' 표, 테스트 페이지 '테스트 목록', 관리자 로그인 링크
- [x] **P2 한글 제목이 글자 단위로 줄바꿈됨**
  - 사이트 전체에 단어 단위 줄바꿈(`word-break: keep-all`)을 적용했습니다. 칸보다 긴 한 단어만 예외로 끊어서(`overflow-wrap: anywhere`) 좁은 카드에서도 넘치지 않습니다. [globals.css](app/globals.css)
- [x] **P3 태블릿(768) 헤더**
  - 메뉴 글자를 12px에서 13px로 키웠습니다. 768에서도 한 줄에 다 들어옵니다.
  - 하단 상담 바는 그대로 폰에서만 보입니다. 태블릿은 헤더의 '상담 요청' 버튼과 상세 페이지 연락처 카드로 충분하다고 판단했습니다.
