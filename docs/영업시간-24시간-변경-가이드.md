# 영업시간을 "연중무휴 24시간"으로 바꾸기

작성: 2026-11-26 · 대표님 결정: 모든 곳 영업시간 = **연중무휴 24시간**

| 어디 | 상태 |
| --- | --- |
| 우리 홈페이지 (sanbon.lineestate.co.kr) | 코드 수정 완료. 배포하면 아래 정보와 검색용 정보(구조화 데이터)가 "연중무휴 24시간"으로 바뀜 |
| 네이버 스마트플레이스 | 직접 바꾸기 (아래 1) |
| 카카오맵 | 직접 바꾸기 (아래 2) |
| 구글 비즈니스 프로필 | 직접 바꾸기 (아래 3) |
| 당근 비즈프로필 | 이미 연중무휴 24시간이라 그대로 |

로그인·비밀번호·인증번호는 직접 넣으세요. 메뉴 이름은 조금 다를 수 있어요.

## 1. 네이버 스마트플레이스
1. https://new.smartplace.naver.com → 사업자 아이디로 로그인 → **선부동산** 선택.
2. **업체정보 → 영업시간 → 수정**.
3. **매일 같아요**(또는 요일 전체 선택) → **24시간 영업** 체크.
4. **휴무일**: 정기 휴무 없음, 공휴일 휴무 체크는 **해제**.
5. 저장 → 네이버 검토 후 반영(보통 하루).

## 2. 카카오맵 (카카오비즈니스 파트너센터)
1. https://business.kakao.com → 카카오 계정 로그인 → **매장 관리 → 선부동산(매장 8662)**.
2. **영업시간 수정** → 모든 요일 선택 → **24시간** 선택.
3. **일요일 휴무**, **모든 공휴일 휴무** 설정을 **지우기**.
4. 저장(반영에 시간 걸림).

## 3. 구글 비즈니스 프로필
1. 구글 검색창에 「내 비즈니스」 또는 https://business.google.com → 사장님 구글 계정.
2. **프로필 수정 → 영업시간** → 월~일 모두 **영업 중** → 시간 칸에서 **24시간 영업** 선택.
3. 저장. (소유 확인 동영상이 끝나야 손님에게 보여요.)

## 다 끝나면
"네이버 / 카카오 / 구글 24시간: 완료 또는 안 됨(이유)"만 알려 주세요.
