## 3. 하면 안 되는 것

- **중개보조원 표시 금지** (법 제18조의2①): 중개보조원에 관한 사항은 광고에 명시할 수 없습니다. 현재 사무소는 대표 1인이고, 소속공인중개사와 중개보조원은 없습니다(2026-11-05 대표 확인).
- **개업공인중개사가 아닌 자의 광고 금지** (법 제18조의2③).
- **부당한 표시·광고** (법 제18조의2④, 영 제17조의2④, 부당광고 고시):
  - 존재하지 않는 매물, 의뢰받지 않은 매물, 중개할 의사가 없는 매물 광고
  - **계약이 체결된 줄 알면서 계속 광고하는 것**. 계약 체결을 통보받으면 3일 안에 삭제해야 합니다
  - 의뢰받은 가격과 다른 가격, 공부와 다른 면적, 해당 매물이 아닌 사진
  - 방향이 실제와 90도 이상 다른 경우, 관리비를 현저히 다르게 표시하는 경우
  - **교통시설까지 거리를 도보거리·도보시간이 아닌 직선거리로 표시하는 것**
  - 중요한 사실을 지나치게 작은 글씨로 쓰거나 빠뜨리는 것
- **명칭** (법 제18조①): 사무소 명칭에 ‘공인중개사사무소’ 또는 ‘부동산중개’를 써야 합니다. 옥외광고물(간판)에는 개업공인중개사 성명을 표기해야 합니다(③).

## 4. 사이트 점검표

### 4-1. 중개사무소 표시 (변경 전 → 변경 후)

| 항목 | 변경 전 | 변경 후 |
|---|---|---|
| 명칭 | **불충분.** 하단에 ‘선 공인중개사’로 표시되어 등록 명칭과 달랐음. 로고와 제목은 ‘선부동산’ | **있음.** 모든 공개 화면 하단과 매물 상세 사이드바에 ‘선부동산공인중개사사무소’ |
| 소재지 | 있음. 다만 등록증 표기와 형식이 다름(‘광림프라자’, ‘(산본동 1135)’) | **있음.** 등록증 표기 그대로 |
| 연락처 | 있음 (휴대폰, 사무실) | 있음 (신고된 두 번호) |
| 등록번호 | **빠짐** | **있음** (하단, 매물 상세) |
| 개업공인중개사 성명 | 있음 (‘공인중개사 김영선’) | 있음 (‘개업공인중개사 김영선’) |
| 중개보조원 표시 | 없음 (적합) | 없음 (적합) |

**사이트 제목 ‘선부동산’에 대해:** 고시 제3조제1호는 광고의 명칭으로 등록증 명칭을 쓰도록 하고 ‘사무소’만 생략할 수 있게 합니다. 따라서 ‘선부동산’만 단독으로 쓰는 것은 명칭 표시로 충분하지 않습니다. 이번 변경으로 모든 공개 화면에 등록 명칭을 함께 표시합니다. 로고와 브라우저 제목의 ‘선부동산’은 브랜드로 남겨 두었습니다. 더 보수적으로 하려면 헤더나 제목도 ‘선부동산공인중개사’(사무소 생략형)로 바꾸는 방법이 있습니다.
