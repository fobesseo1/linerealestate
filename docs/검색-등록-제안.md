## 제안 — A. 코드 (제가 함, 각 항목 시험 포함)

1. **사진 설명을 매물 제목으로**: 사진 이름이 파일 이름이면 `「매물 제목」 사진 1` 식으로. 이미지 검색·네이버 이미지에 매물이 잡히게. (자료는 안 바꾸고 화면에서만)
2. **매물마다 구조화 데이터**: 매물 종류(임대·매매)·가격·주소(공개한 것만)·사진·사무소를 검색엔진이 읽는 형식으로 + 이동 경로(홈 › 매물 › 이 매물). 없는 값은 넣지 않음.
3. **RSS 피드** `/rss.xml`: 최근 매물·사례 목록. 네이버 서치어드바이저에 제출.
4. **새 매물 자동 알림(IndexNow)**: 관리자 화면이나 채팅으로 매물을 승인·공개하면 그 주소를 빙·네이버·다음에 바로 알림. (구글은 IndexNow를 안 받음 → 사이트맵으로)
5. **소유확인 태그 넣기**: 구글·네이버·빙·다음 인증 값을 Coolify 환경변수에 넣고 재배포 (코드는 1단계에서 준비됨).
6. (작은 것) 매물 목록 페이지가 지금 첫 12개만 링크로 보임 → 페이지 번호도 링크로. 홈에는 이미 71개 전부 링크가 있어 급하지 않음.
