# 선부동산 전체 디자인 기준 — A-1

이 문서가 공개 사이트 디자인의 유일한 기준이다. 이전 Airbnb 기반 문서(DESIGNstyle-lineestate.md)는 2026-10-13 사용자 결정으로 폐기했다.

2026-10-13 사용자 승인: A-1 `제일 다이나믹 + 캐릭터`를 공개 사이트 전체 디자인으로 채택.
기준 화면: 현재 공개 홈 https://linerealestate.vercel.app/ (시안 비교 페이지는 채택 후 삭제)

## 브랜드

- 상호: 선부동산 / LINE REAL ESTATE. 담당 공인중개사 김영선.
- 주색 `#E00B41`; 짙은 배경 `#19191F`; 짙은 카드 `#24242C`; 밝은 배경 `#F5F5F6`; 흰색 `#FFFFFF`.
- 주색을 황금색·황토색·어두운 갈색으로 대체하지 않는다.
- 짙은 헤더·푸터: `/logo-white.svg`. 밝은 배경: `/logo.svg`. 원본 경로를 유지한다.
- Pretendard Variable, 100–900. 주요 제목 800–850, 본문 400–500. 라이선스는 `public/fonts/LICENSE.txt`.

## 화면과 여백

- 섹션 배경은 화면 양끝까지 이어지며 바깥 고정 폭으로 잘리지 않는다.
- 일반 페이지 내용은 최대 1440px, 좌우 5% 여백(`page` 유틸리티). 화면 끝까지 이어지는 홈 섹션은 같은 정렬의 `px-gutter`.
- 여백·간격·크기는 가능하면 4px 배수(Tailwind 기본 간격 단위)를 사용한다. 글자 크기는 아래 토큰 단계를 따른다.
- PC: 매물 카드 3열, 상세는 본문과 상담 사이드바 2열. 모바일: 카드·상세 1열.
- 카드·사진·지도는 기울이지 않는다. 붉은 강조선, 직선 카드, 가벼운 그림자를 사용한다.
- 헤더·내비게이션·푸터는 모든 공개 화면에서 같은 디자인을 사용한다. 관리자 화면은 별도.

## 홈

검증된 A-1의 큰 사진, 제목, 붉은 안내 띠, 실제 공개 매물 기반 가격·숫자, 흐르는 매물 띠,
매물 검색·카드·중개 완료 사례·상담 안내를 사용한다. 시안 선택 메뉴와 추천 의견은 실제 홈에 표시하지 않는다.
공통 헤더의 임대차·매매·사례·비용 비교·상담 과정 내비게이션은 유지한다.
시연용 가상 매물은 2026-10-14 사용자 결정으로 완전히 삭제했다. 옛 가상 상세 링크(`/#case/...`)는 매물 목록으로 연결한다. 비용 비교의 명시적 가정 예시는 유지한다.

## 매물과 사례

- 공개 관리 데이터와 SUN 번호·기존 링크를 그대로 사용한다. 거래 사실·사진·원본을 수정하지 않는다.
- 실제 목록에 가격을 표시하고 업종·월세·검색·찜 필터를 지원한다. 찜은 기존 로컬 브라우저 저장 방식을 사용한다.
- 상세는 제목·상태·사진·거래 조건·지도·상담을 우선한다. 미확인 항목과 완료 사례 구분을 유지한다.
- 사진 종횡비는 유지한다. 상세 큰 사진은 contain, 목록 썸네일은 cover. 지도·핀 동작을 변경하지 않는다.

## 움직임과 캐릭터

- 실제 매물·사례 사진: 양옆 54px 원형 버튼 안 붉은 삼각형(모바일 44px). hover 시 붉은 배경·가벼운 빛 테두리·짧은 삼각형 이동, 사진 전환은 0.32초 등장. 자동 넘김은 하지 않는다. 이전·다음 순환, 선택 썸네일 자동 가로 스크롤, 갤러리 포커스 시 좌우 방향키, 모바일 좌우 스와이프를 지원한다. 움직임 끄기·OS reduced-motion에서는 효과를 끈다.

- 홈 사진은 A-1의 1.8초 전환, 빠른 사진 등장·버튼 반응·매물 띠를 유지한다.
- 실제 목록 카드: 짧은 등장과 hover 이동·사진 확대. 긴 정보를 읽는 상세는 자동 교체·강한 반복 이동 없음.
- 홈은 스크롤을 따라 이동·점프하는 캐릭터 한 개. 매물에 포인터·키보드 포커스를 주면 해당 제목 안내.
- 실제 문의 입력은 안내 캐릭터, 실제 POST 요청 중 `think`, 서버 접수 완료 `success`, 실패/검증 오류 `fail`.
- 캐릭터는 화면 밖·숨겨진 탭에서 재생을 멈추며, 실패한 요청을 완료로 표현하지 않는다.
- 공통 '움직임 끄기/켜기'는 홈과 문의 캐릭터에 전달한다. OS의 reduced-motion을 존중한다.
- 모바일 고정 전화·문의 영역과 캐릭터가 겹치지 않게 간격을 확보한다. 캐릭터 숨기기 유지.

## 상담과 정보 페이지

문의 양식·개인정보 동의·입력 검증·중복 요청 방지·저장/API·카카오/이메일/시트 흐름은 유지한다.
비용 비교는 가정 수치임을 계속 표시한다. 상담 과정은 짙은 제목 영역과 붉은 강조선, 흰 단계 카드로 통일한다.

## 구현과 검증

- 스타일은 Tailwind CSS v4 유틸리티로만 작성한다. 디자인 토큰은 `app/globals.css`의 `@theme`에 있다.
  - 색: `brand`(#E00B41)·`brand-hover`·`brand-soft`·`brand-pale`·`brand-tint`, `ink`(#19191F)·`ink-raised`·`ink-line`, 사이트 전용 `gray-50…900`.
  - 글자 크기: `text-micro`(9) `tiny`(10) `caption`(11) `xs`(12) `body`(13) `sm`(14) `md`(15) `base`(16) `lead`(17) `lg`(18) `xl`(20) `2xl`(24). 굵기: `font-demibold`(650) `font-strong`(750) `font-heavy`(850).
  - 화면 구간: 모바일 `max-md`(≤760px), 태블릿 `max-lg`(≤1100px), 고정 도구 `2xl`(≥1661px).
  - 새 색·크기가 필요하면 임의값을 반복하지 말고 토큰을 추가한다. `lib/utils.ts`의 `cn`에도 사용자 정의 글자 크기·굵기를 등록한다.
- 공통 UI는 shadcn/ui 방식 컴포넌트(`components/ui`): Button, Dialog, Input/Textarea, NativeSelect, Badge, Card. shadcn 의미 토큰(`--primary`, `--border` 등)을 `:root`에 두고, 관리자 화면은 `.admin-shell`에서 같은 변수를 덮어 기존 무채색 디자인을 유지한다.
- 공개 화면 구성: `app/(site)/layout.tsx` → `components/site/site-shell.tsx`(헤더·푸터·모바일 문의 바·고정 도구·상담창·광고 팝업·옛 `#` 주소 연결). 홈은 `components/home`, 매물·사례는 `components/listings`.
- 주소: `/`, `/listings`(`?type=lease|sale`, `industry`, `rent`, `q`, `saved=1`), `/property/SUN-xxxx`, `/works`, `/works/SUN-xxxx`, `/compare`, `/process`. `/sale`은 매매 목록으로 연결한다. 매물·사례 페이지마다 제목·설명·공유 이미지를 만든다.
- 공개 자료는 서버에서 30초 캐시로 읽고(`lib/content/public.ts`), 열린 화면은 `usePublications`가 계속 새로 고친다.
- `SiteMotionControl/useSiteMotion`: 공개 화면 모션 설정.
- 매물 목록·상세·사례·검색·찜·지도·사진 전환·문의창·필수 검증을 확인한다.
- PC/모바일 수평 넘침, 글자 대비, 문의 버튼 가림을 확인한다. 실제 고객을 대신해 테스트 문의를 보내지 않는다.

2026-10-13 홈 대표 매물 카드 비율 수정: PC 사진은 1.9:1, 모바일은 1.65:1 표시 영역으로 원본 종횡비를 유지하며 cover 처리. 정보 영역의 제목 최소 높이와 넓은 여백을 제거하고 주소·제목·가격·전환 버튼을 촘촘히 배치. 긴 제목은 줄바꿈으로 전체 표시하며 억지 고정 높이로 자르지 않는다.

필터/고정 도구 기준: 업종·월세 선택 높이 44px, PC 14px/모바일 16px. 고정 찜·상담 도구는 1440px 콘텐츠 바깥 여백에 두고, 1660px 이하에서는 겹침을 막기 위해 숨긴다. 상단 메뉴와 모바일 문의 바는 유지한다. 점검 기록: docs/ui-audit-2026-10-13.md.

광고 팝업: 사용자 제공 30초 세로 영상은 public/videos/seon-ad-vertical-v2.mp4 (540×960, H.264/AAC, 약 1.31MB). 원본 1080×1920 14.2MB는 유지. 홈 방문 세션당 한 번만 2.2초 후 자동 열기, 기본 muted/playsInline/controls, 반복 재생 없음. 메뉴 ‘광고 영상’으로 재열기, 닫기·하루 숨김·상담 연결 지원. 상담 모달과 동시에 자동 열지 않으며 닫힌 팝업 영상은 DOM에서 제거한다.
